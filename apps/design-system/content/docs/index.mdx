Welcome to the **Assembly Design System**! 

Assembly is a modern, premium component ecosystem engineered for visual elegance, strict accessibility (a11y), and zero developer friction. Built on top of Radix UI primitives and styled with modern Tailwind CSS v4 coordinates, Assembly gives you complete control over your frontend presentation layer.

## Core Features

* **Outfit Typography**: Features clean, high-fidelity Google Fonts typography, elevating the overall design aesthetics.
* **Fira Code with Ligatures**: All syntax-highlighted codeblocks feature full OpenType ligature support (`=>`, `===`, `!=`) for a premium coding manual feel.
* **Segmented Previews**: Swap seamlessly in-place between live component previews and formatted code blocks using Assembly's native Navigation Menu components.
* **Spacious 450px Viewports**: Never worry about overlapping dropdowns, popovers, or calendars—previews are spacious and responsive.
* **Developer Setup CLI**: Download and configure components automatically into your project using our lightweight interactive CLI.

---

## Design Philosophy

### Why copy/paste and not a rigid package?

The core idea of Assembly is to **give you ownership and control over your source code**. 

One of the major drawbacks of packaging components in a strict, bloated npm dependency is that the aesthetic is coupled with the implementation. If you want to change a padding, tweak a state transition, or alter a border-radius, you are often blocked. 

With Assembly:
1. You start with sensible, highly polished defaults.
2. You run a single command to drop the code directly into your folder.
3. You own the component files, allowing you to edit the markup to fit your design system's exact personality.
